# Step 1: Start MAVProxy
1. Open Miniforge Prompt
2. Type the following:
   conda activate yolo_gpu
   cd Desktop\Drone_yolo
   mavproxy.py --master=COM15,57600 --out=udp:127.0.0.1:14550 --out=udp:127.0.0.1:14551
   
# Step 2: Open QGroundControl
1. Launch QGroundControl normally.
2. It will automatically connect to MAVProxy via UDP port 14550.

# Step 3: Run the Inference Pipeline
1. Open a SECOND Miniforge Prompt
2. Type the following:
   conda activate yolo_gpu
   cd Desktop\Drone_yolo
   python inference_stream.py

# Step 4: Operator Targeting
1. The OpenCV "Operator View" window will pop up.
2. Left-click on any detected bounding box inside this window.
3. The drone will automatically be sent a GUIDED command to fly to that exact GPS coordinate!
